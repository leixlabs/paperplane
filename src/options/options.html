Paperplane

点击工具栏图标 → 本地 AI 摘要 → 直发 Telegram 频道

零后端架构 网页正文只在本机由 Chrome 内置 AI（Gemini Nano）处理，仅最终摘要通过 HTTPS 发往 api.telegram.org。

1 Telegram 连接

在 Telegram 找 @BotFather → /newbot 获取。也可直接写死在 src/background/config.js。

用 @用户名 最省事；私有频道请填 -100… 数字 ID。务必先把 Bot 拉进频道并设为管理员（可发布消息）。

2 本地 AI 摘要

内置 AI 不可用时，降级引擎会用抽取式算法复现这四种类型，但降级摘要是抽取原句、无法翻译，会沿用原文语言。
输出语言走 Chrome 的 outputLanguage 参数，它目前只接受 de / en / es / fr / ja；选简体中文时该参数会被省略，由模型跟随原文自动输出中文（这样反而更准）。

使用与排错

      
    
        
  • 快捷键：Alt+Shift+T，可在 chrome://extensions/shortcuts 修改。
    • 
        
  • 徽标：··· 处理中 · ✓ 成功 · SKIP 已发过被去重跳过 · ERR 失败（悬停图标看具体原因）。
    • 
        
  • 模型没就绪：在 chrome://flags/#optimization-guide-on-device-model 选 Enabled BypassPerfRequirement，再在 chrome://components 更新 Optimization Guide On Device Model。需要 Chrome 127+、磁盘 ≥ 22GB。
    • 
        
  • 发不出消息：90% 是 Bot 没被设为频道管理员，或 CHANNEL_ID 写错。
